## 写真を追加する

各人物の `images/inbox/` にそのまま入れてください。最初から名前を揃えたり、説明ファイルを作ったりする必要はありません。
誰の画像か決めにくい集合写真は `group/images/` に置きます。

整理するときに、採用したサブ画像を `images/variations/` に移し、人物ページに画像と用途を追記します。
顔・体格などの基準として明示的に採用したものだけ `images/base/` に置き、Visual Guideに現在の基準を記録します。
画像の追加だけで設定や基準を変更しません。候補はinboxに残せます。

名前を整理する場合は `2026-10-06-cafe-01.jpg` のように日付・場面・連番を使います。
サブ画像には「衣装のみ参考」「髪型のみ参考」などを添えると便利です。
設定のない人物・部屋の情報は推測で補いません。

## 保存場所

設定と参照画像の原本はここで一元管理します。
投稿の台本・企画は `contents/`、動画で読み込む場面素材は `public/`、実装は `src/` に置きます。
制作のためpublicへ派生素材を置く際は、企画の素材一覧に元画像のパスを記録してください。
