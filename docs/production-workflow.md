# 小川莉奈 制作フロー

## 基本構成

Character Bible → ChatGPT Images → マスター画像（正面・横顔・全身）→ Codex（司令塔）→ Gen-4.5 / Veo 3.1 / Seedance → 動画素材MP4 → Remotion → TikTok / Shorts。

全体図は[プロジェクトREADME](../README.md#制作フロー)を参照。

## 役割分担

| 工程 | 担当 | 入力 | 成果物・責任範囲 |
|---|---|---|---|
| キャラクターの定義 | Character Bible | 確定した設定 | 人物像・価値観・外見の正史 |
| 外見の基準作り | ChatGPT Images | Character Bible、Visual Guide、既存の基準画像 | 正面・横顔・全身のマスター画像 |
| 制作の統括 | Codex | 企画、マスター画像、各ガイド | 台本、絵コンテ、カット別生成指示、モデル選択、素材管理・確認、Remotion実装 |
| 動作映像の生成 | Gen-4.5 / Veo 3.1 / Seedance | 共通のマスター画像、必要な開始フレーム、カット別生成指示 | 動画素材MP4 |
| 編集・仕上げ | Remotion | 採用したMP4、字幕、音声・音楽・効果音、ロゴ | カット編集、字幕、BGM、SE、ロゴ、音量調整、完成MP4 |
| 配信先 | TikTok / YouTube Shorts | 確認済み完成MP4 | 投稿用縦動画 |

これはプロジェクトの制作方針であり、サービスの機能保証や接続状況を示すものではない。モデルごとの入力形式・尺・音声対応・利用条件は実行時に確認する。Seedanceのバージョンは未指定。Codexからの実行方法は、その時点で使える接続機能・API・ブラウザ操作に合わせる。

## マスター画像

- 設定は[Character Bible](../character/character-bible.md)、外見の参照方法は[Visual Guide](../character/visual-guide.md)に従う。
- 既存の `public/assets/reference/rina-base.jpg` 左下のボブを主基準とし、ChatGPT Imagesで正面・横顔・全身を揃える。
- 顔立ち、体格、髪、口元のホクロが画像間で一致するか確認してからマスターとして採用する。生成しただけの画像は候補として扱う。
- カット専用の衣装・背景・ポーズを持つ開始フレームは、マスターから派生させる。場面画像を自動的にマスターへ昇格させない。
- 元の基準画像を保存し、採用版を置き換える際も版を分けて履歴を残す。

## 動画素材から仕上げまで

1. Codexで台本・尺・カット構成を整理し、各カットの参照画像と生成指示を準備する。
2. Gen-4.5、Veo 3.1、Seedanceから利用可能なモデルを選ぶ。まず短い試作で人物の同一性と動作を確認する。すべてのモデルで生成することは必須ではない。
3. 生成したMP4を保存し、顔、手足、道具、背景、動作、カット間の連続性を確認する。失敗した素材は完成動画に使わない。
4. 採用素材をRemotionへ取り込み、カット編集、字幕、BGM、SE、ロゴ、音量を調整する。BGM・SE・ロゴは企画に必要なものを使用し、全項目の追加を必須にしない。
5. 投稿用MP4を書き出し、通常速度で全編確認する。TikTok / Shortsへの投稿操作は書き出しと分けて扱う。

## 保存先の規約

以下は今後の素材保存先。ディレクトリやファイルが存在することを意味しない。

| 保存先 | 内容 |
|---|---|
| `public/assets/reference/rina-base.jpg` | 加工しない原本の基準画像（登録済み） |
| `public/assets/rina/masters/` | 正面・横顔・全身のマスター候補と採用版 |
| `public/assets/rina/<テーマ>/` | 衣装・場面の参照画像、開始フレーム |
| `public/assets/video/<企画ID>/` | 生成した動画素材MP4 |
| `public/assets/audio/<企画ID>/` | BGM・SE・音声 |
| `public/assets/branding/` | 採用したロゴ等 |
| `contents/<企画ID>/` | 台本、生成指示、素材一覧、確認結果 |
| `out/<企画ID>/` | Remotionから書き出した完成MP4 |

各企画の素材一覧には、カットID、使用モデルとバージョン、参照画像、生成指示、保存先、尺・解像度・fps、音声の有無、確認結果、採用・不採用を記録する。実行前の予定値と実測値を区別する。
